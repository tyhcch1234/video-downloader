設定說明

這個頁面是靜態網頁，需要一個 yt-dlp 後端才能真正下載影片。設定一次即可。

為什麼？ GitHub Pages 只能寄存檔案，不能執行程式。YouTube 的串流簽名、Instagram／Facebook 的登入 session 都必須在伺服器端處理，瀏覽器無法直接抓取。

① 啟動後端（本機最快）30 秒

需要 Python 3.9+：

pip install -r requirements.txt
python app.py

然後開 http://localhost:8000，這個網址由後端直接提供頁面，前後端同源，無需任何設定即可使用。

② 部署後端（讓這個 GitHub Pages 頁面可用）

Render（免費）

New → Web Service → 連結此 repo → Runtime 選 Docker（含 ffmpeg）→ 部署。

完成後得到 https://xxx.onrender.com，貼到右上角齒輪儲存即可。免費方案閒置會休眠，首次喚醒約 30–60 秒。

自己的 VPS / Docker

docker build -t video-downloader .
docker run -d -p 8000:8000 video-downloader

記得掛 HTTPS 反向代理：本頁是 https，不能呼叫 http 後端。

③ 填入伺服器網址

按右上角齒輪 → 貼上後端網址 → 「測試連線」→「儲存」。網址存在瀏覽器 localStorage，換裝置要再填一次。

Instagram / Facebook / 私人內容

這些內容幾乎都需要登入。匯出 cookies.txt（Netscape 格式）放在伺服器，啟動時加：

COOKIES_FILE=/path/to/cookies.txt python app.py

cookie 等同帳號憑證，切勿提交到公開 repo。

限制

  • 任務與暫存檔存在伺服器記憶體／暫存目錄，重啟即消失，2 小時後自動清除。
  • 只處理單一影片連結，播放清單只取第一條。
  • 網站改版可能令下載失效，屆時更新 yt-dlp 即可。
